# "Real Thai" (เรียลไทย) — the native-format style guide

The descendant of the classic Thai TVC canon, built for the 20–30 generation:
keep the DNA (absurdity played straight, the twist, the heart under the joke),
swap the vehicle — the ad camouflages itself as content they already scroll.

## The 5 rules

1. **Native camouflage** — open as a format they consume daily (live commerce,
   POV vlog, CCTV, mock-interview, voice note). Lo-fi assumed, timestamps, format
   UI on screen. Zero ad markers.
2. **The classic Thai twist invades the format** — the absurd-played-straight
   arrives INSIDE the fake content's frame, not beside it.
3. **The confession** — the ad admits being an ad in the last second
   (**« ใช่ค่ะ นี่คือโฆษณา »** — *"yes, this is an ad"*). Honesty about the game IS
   the new twist; it is the line this generation rewards and quotes.
4. **Sound-on native** — burned-in Thai subtitles, works muted AND with sound.
5. **P'Fon is serial** — the recurring ตัวตึง (GOAT) character, episode after
   episode; serialized attachment is the engine (the BL-series / sitcom logic).

## Format UI in post — legal note

Fake live/social UI (chat bubbles, hearts, viewer counters, timestamps) is always
composited in post and must be a GENERIC look-alike — never TikTok's or any
platform's exact trademarked assets.
